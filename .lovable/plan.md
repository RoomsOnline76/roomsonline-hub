# Cheetah Plains Owner Slides — align with the Golden Final Report

The "Cheetah Plains Extra" currently produces three slides (Nationality, Top Travel Partners, Declined Bookings). The signed-off final report is a 13-page owner pack. This plan closes the gap so the optional extra produces the full pack, using only data already extracted from the uploaded owner-report PDF/workbooks.

## What exists today

- Extractor (`priorOwnerReport.ts`) already reads: as-of date, the current-year fiscal grid, the forward-year grid, declined bookings (value, agents, reason, % of monthly revenue), nationality rows and partner rows for both years.
- Slide builder (`specialReportHtml.ts`) has one shared landscape-A4 shell (left title rail + notes, terracotta header band, blush alternating rows, footer rule with logo) and three table slides.
- The extra is opt-in per property (`special_report_set = 'cheetaplains'`) and per run, generated by `cheetaplains-special-reports`.

## What the golden pack adds

| Golden page | New slide | Data source |
|---|---|---|
| 1 | Business on the Books Analysis — YTD narrative with quarter blocks and Key Takeaways | derived from the current-year grid (quarter roll-ups) + TOBI prose |
| 2, 6 | Revenue Report grid for FY current and FY forward (Confirmed BOB, Budget, Active Enquiries, Variance to Budget, BOB STLY, BOB LY Actual, Variance to STLY, Confirmed BOB + Active Enquiries, three occupancy columns) with Q1–Q4 and Total rows | extracted fiscal grids |
| 3, 7 | Grouped bar chart "BOB, Budget & LY Actual" per fiscal year | same grids |
| 5 | Distribution, Reservations and Revenue Update — Reservations Synopsis + Market Challenges | text captured from the pack, editable |
| 9, 10, 13 | Declined / Partners / Nationality (already built) | existing |
| 11, 12 | Top Producing Partner Trends — inbound and international outbound, multi-year columns | partner tables per year in the pack |

## Build steps

1. **Extractor**: add capture of the page-5 narrative blocks (Reservations Synopsis, Market Challenges) and the multi-year partner trend tables (year columns 2023–2028) to `OwnerReportExtract`.
2. **Slide builders** in `specialReportHtml.ts`, all reusing the existing shell so branding and footer stay identical:
   - `buildRevenueGridSlide` — left rail shows the fiscal-year title, combined revenue and variance callouts, and the BOB/STLY/LY legend; grid uses grey Q rows and a Total row, green positive / red negative variance text.
   - `buildBobChartSlide` — grouped bars (BOB terracotta, Budget black, LY BOB blush) rendered as inline SVG so it prints without a chart runtime.
   - `buildNarrativeSlide` — quarter-headed prose slide used for both the BOB Analysis and the Distribution/Reservations update.
   - `buildPartnerTrendSlide` — multi-year partner columns, inbound and outbound variants.
3. **Quarter maths** helper: Q1 = Mar–May, Q2 = Jun–Aug, Q3 = Sep–Nov, Q4 = Dec–Feb, Total = fiscal year. Used by both the grid and the narrative so the numbers cannot diverge.
4. **Edge function** `cheetaplains-special-reports`: emit the new `report_key`s (`bob_analysis`, `revenue_grid_current`, `bob_chart_current`, `revenue_grid_forward`, `bob_chart_forward`, `distribution_update`, `partner_trend_inbound`, `partner_trend_outbound`) in golden-pack order, skipping any slide whose source data is absent, and keep the existing three.
5. **Review UI** (`SpecialReportsCard`): list the slides in pack order with a per-slide open link, show a "source data missing" note for skipped slides, and keep them inside the existing Slide Organizer ordering.
6. **Narrative editing**: the two prose slides pull from the extracted text and remain editable in the run review, so an owner-report month can be re-worded without re-uploading.

## Content integrity

No figure, agent name, partner name or commentary is invented. Every number comes from the uploaded pack or is a roll-up of it; any slide whose data was not found is skipped rather than filled with placeholders, and the run review names which pages were skipped.

## Technical notes

- All slides are stand-alone `text/html` landscape-A4 documents in the `revenue-reports` bucket, indexed in `report_special_reports` keyed by `run_id,report_key` — same contract as today, no schema change needed beyond new key values.
- Charts are hand-emitted SVG (no new dependency), colours from the existing branding resolution (`brand_source`, `brand_primary`), falling back to the Cheetah Plains house palette.
- Opening a slide continues to go through the branded domain viewer route; no direct storage URLs.
