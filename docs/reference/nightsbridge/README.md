# NightsBridge Reference Documents

Golden reference files for the Revenue Reports platform (`reports.roomsonline.co.za`).

## Folder structure

| Folder | Purpose |
|--------|----------|
| `source/` | Raw `bookingsummary (xx).xlsx` files exported from NightsBridge |
| `consolidated/` | Target consolidated Excel (OTB RR + Fin Year + Historical) |
| `final-report/` | Final visual PDF report (Canva origin) |

These files are the single source of truth for parser logic, aggregation rules, Excel generation and visual draft fidelity.
